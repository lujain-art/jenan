# MICROVERSE ESCAPE — THE CELLVERSE ADVENTURE
## الهروب من العالم المجهري — رحلة داخل الخلية

لعبة صفية تفاعلية ثلاثية الأبعاد لمادة الأحياء — الصف التاسع (الخلية: التراكيب،
الغشاء البلازمي، النقل الخلوي، الأسموزية، الحويصلات).

ثلاثة مستكشفين صُغّروا بعد اضطراب في الطاقة، فوجدوا أنفسهم داخل خلية حيّة.
بوابة الخروج محطّمة، وستة أقفال أمنية تغلقها. كل مهمة تعيد نظامًا إلى العمل
 وتمنحكم **مفتاح هروب**. ستة مفاتيح = بوابة مفتوحة = خروج.

اللعبة مكتفية بذاتها بالكامل: لا حسابات، لا خادم، لا إنترنت، ولا أي رابط خارجي.
افتحوا `index.html` والعبوا.

---

## 1. التشغيل دون إنترنت / Running offline

### الطريقة الأسهل — من الملف مباشرة

1. انسخوا مجلد `microverse-escape` كاملًا إلى جهاز الحصة (أو إلى ذاكرة USB).
2. افتحوا `index.html` في Chrome أو Edge أو Firefox.
3. اضغطوا **ابدأ المغامرة** لتفعيل الصوت، ثم أكملوا المقدمة السينمائية.

كل الملفات محلية: Three.js r147، الخطوط العربية، الموسيقى والمؤثرات المولّدة
داخل المتصفح، ١٦ صورة شخصيات متحركة WebP، و٨٩ مقطعًا صوتيًا عربيًا داخل
`assets/voice/`. لا يحتاج الجهاز إلى اتصال بالإنترنت أثناء اللعب إطلاقًا.

> تم التحقق من التشغيل المباشر من القرص (`file://`) على دقة 1366×768: الخطوط
> والصور المتحركة والمشهد ثلاثي الأبعاد وقطع الصوت — كلها تعمل بلا أي خطأ.

### طريقة بديلة — خادم محلي (اختياري)

من مجلد المشروع:

```bash
python -m http.server 4180 --bind 127.0.0.1
```

ثم افتحوا: `http://127.0.0.1:4180/`

### المتطلبات

- متصفح حديث يدعم WebGL (Chrome / Edge / Firefox — إصدار 2022 أو أحدث).
- بطاقة رسوميات مدمجة تكفي؛ اللعبة تعمل على أجهزة الصف بدون GPU منفصل.
- لا حاجة إلى تسجيل دخول، قاعدة بيانات، أو اتصال بالشبكة.

## 2. العرض على البروجكتور / Projection

- اللعبة مصممة بنسبة **16:9**. الدقات المدعومة والمختبرة:
  **1920×1080**، **1366×768**، **1280×720**.
- افتحوا المتصفح في وضع **ملء الشاشة (F11)**، ثم من أدوات المعلم اختاروا
  **ملء الشاشة** لإخفاء شريط المتصفح.
- استخدموا تكبير المتصفح **100%**، وتجنّبوا تكبير النظام.
- مدة الحصة المستهدفة: **٣٠–٤٠ دقيقة** (المقدمة ≈ ٣ دقائق، كل مهمة ≈ ٥ دقائق).
- اللعب جماعي أمام جهاز واحد: الفريق يقرر معًا والمعلم يضغط الأزرار.
  اسم الفريق اختياري ويظهر في الشهادة فقط.
- مستوى الصوت المقترح ٧٠–٨٥%. إذا كانت القاعة ذات صدى، اضبطوا **الموسيقى**
  أقل من **أصوات الشخصيات**.
- شريط التحكم أعلى الشاشة: الصوت العام، الموسيقى، المؤثرات، أصوات الشخصيات،
  والإيقاف المؤقت. زر الكتم يوقف كل الأصوات فورًا، ويمكن إكمال اللعبة كاملة
  بلا صوت — كل حوار مكتوب على الشاشة: فقاعات الشخصيات خارج المهمة، وشريط
  ترجمة باسم المتحدث داخلها.

### أدوات المعلم

زر **المعلم** داخل المهمة، أو أيقونة الترس على الخريطة:

| الأداة | الوظيفة |
| --- | --- |
| إيقاف مؤقت / استئناف | تجميد المشهد والصوت وإظهار بطاقة مناقشة |
| إعادة المهمة الحالية | البدء من أول خطوة في المهمة دون مسح التقدّم |
| خريطة المهام | الانتقال بين المهمات المفتوحة |
| تخطّي الحوار | إسكات الحوار الحالي والمتابعة |
| تخطّي الغوص | تجاوز مشهد التصغير السينمائي |
| تلميح | جملة إرشادية من الشخصية المناسبة للموقف |
| ملء الشاشة | عرض مثالي على البروجكتور |
| إعدادات الصوت | مستويات الموسيقى والمؤثرات وأصوات الشخصيات + اختبار النطق |
| إعادة اللعبة من البداية | حذف التقدّم والنجوم بعد تأكيد صريح |
| الشهادة | فتح شهادة المستكشف المجهري في أي وقت |

`Esc` يغلق النوافذ المفتوحة (الإعدادات، أدوات المعلم، الشهادة، الإيقاف المؤقت).

أثناء كلام الشخصيات داخل المهمة تُقفل اللوحات الجانبية حتى تنتهي الجملة، لذلك
تظهر فوق شريط الترجمة زرّة **تخطّي الحوار** دائمًا بجانب كل جملة منطوقة —
اضغطوها بالفأرة لقطع الصوت فورًا ومتابعة اللعب. لا تظهر هذه الزرّة إلا أثناء
جملة منطوقة، فلا تزاحم المشهد في بقية الوقت. للمقدمة السينمائية ومشهد التصغير
زرّا تخطٍّ خاصّان بهما ظاهران دائمًا.

## 3. المهمات الست ومفاتيح الهروب

| # | المهمة | مفتاح الهروب | المحتوى العلمي |
| --- | --- | --- | --- |
| ١ | مملكة العضيات | مفتاح العضيات | البلاستيدات الخضراء، البيروكسيسوم، الجسم المركزي، الهيكل الخلوي، الأهداب، الأسواط، الفجوات |
| ٢ | متاهة الغشاء البلازمي | مفتاح الغشاء | بناء الطبقة الثنائية، إغلاق الفجوات، العبور المباشر مقابل البروتينات الناقلة |
| ٣ | أنفاق النقل الخلوي | مفتاح النقل | الانتشار البسيط، الانتشار المُيسّر، النقل النشط (ATP)، أثر الحرارة |
| ٤ | غرفة الأسموزية | مفتاح الماء | منخفض / متساوي / مرتفع التوتر في الخلية النباتية والحيوانية، وعيّنتان مخفيتان |
| ٥ | كهوف الحويصلات | مفتاح الحويصلات | البلعمة، الشرب الخلوي، الإخراج الخلوي، وميزانية ATP |
| ٦ | الهروب الأخير | مفتاح الهروب | سيناريو مترابط يدمج كل ما سبق: فحص ← تحليل ← إصلاح ← توجيه المفاتيح ← خروج |

كل مهمة لها: مقدمة سينمائية، هدف، مشهد ثلاثي الأبعاد تفاعلي، حوار متحرك بصوت
عربي، تغذية راجعة فورية، ونجوم من ١ إلى ٣ حسب الأداء. لا أسئلة اختيار من
متعدد ولا حفظ إجابات — الاستنتاج من المشاهدة.

### المهمة السادسة: سيناريو واحد متصل

أربع مراحل متتابعة داخل مشهد واحد:

1. **افحصوا** — البوابة أولًا، ثم كل نظام متوقف.
2. **حلّلوا** — لكل عطل ثلاث فرضيات؛ اختاروا التفسير الصحيح لا الأقرب إلى الظن.
3. **أصلحوا** — شغّلوا العملية الصحيحة لكل نظام، واضبطوا المحلول على التوتر
   المتساوي بالمنزلق.
4. **وجّهوا** — ستة مفاتيح في ستة مقابس، كل مفتاح بمقبس وظيفته.

ثم يخرج الفريق: يُفتح القفل، تنطلق حزمة الضوء، وتحتفل الشخصيات.

### الخريطة والبوابة

الخريطة تعرض المواقع الستة مع حالتها (مقفلة / مفتوحة / مكتملة) ومفاتيح الهروب
الذهبية. بوابة الهروب في وسط الخريطة تبدأ **مطفأة تمامًا**، ويضيء قوس من
أقواسها الستة مع كل مفتاح — حتى تكتمل الطاقة ويخرج الفريق.

### الشخصيات

| الشخصية | الدور | الصوت |
| --- | --- | --- |
| **نوفا** | قائدة الفريق، تشجّع وتوجّه | `ar-SA-ZariyahNeural` |
| **بيب** | رفيق مضيء صغير، فضولي وحماسي | `ar-SY-AmanyNeural` (نبرة عالية) |
| **أوربت** | روبوت تحليلي طريف، يعطي المعلومات والتحذيرات | `ar-LB-RamiNeural` |

الشخصيات الثلاث صور متحركة حقيقية (WebP بشفافية، ٨–١٦ إطارًا لكل حالة تعبير:
سكون، كلام، فرح، حزن، اندهاش، تلويح). لا إيموجي ولا رموز بديلة. تعبير كل
شخصية مرتبط بالحدث: خطأ → اندهاش أو حزن، نجاح → فرح، كلام → حركة الفم.

## 4. التحكم

- **الفأرة**: اضغطوا على التركيب أو المادة لتحديدها، ثم اضغطوا على الهدف.
  السحب والإفلات متاح أيضًا لبطاقات الوظائف والمواد.
- **تدوير المشهد**: اسحبوا بالزر الأيسر. **التقريب**: عجلة الفأرة.
- **خريطة المهام**: كل مهمة تُفتح بعد إكمال التي قبلها، بالترتيب.
- **شهادة المستكشف المجهري**: تظهر بعد إنهاء المهمات الست. زر
  **طباعة / حفظ PDF** يفتح نافذة الطباعة؛ اختاروا «حفظ كـ PDF» لنسخة رقمية،
  أو اطبعوها على ورق A4 أفقي.

## 5. التقدّم والحفظ

- يُحفظ التقدّم محليًا في `localStorage` تحت المفتاح `microverse-progress-v1`.
- المحفوظ: اسم الفريق (اختياري)، النجوم، المهمات المكتملة، المهمة الأخيرة،
  تاريخ الإنجاز، ورمز الشهادة.
- **لا تُرسل أي بيانات إلى أي خادم**، ولا يُعدّل أي شيء خارج المتصفح.
- لإعادة الضبط: **أدوات المعلم ← إعادة اللعبة من البداية** (يتطلب تأكيدًا).
- الشهادة تعرض: **شهادة المستكشف المجهري / MASTER MICROSCOPIC EXPLORERS**،
  اسم الفريق، المهمات المكتملة من ٦، مفاتيح الهروب من ٦، مجموع النجوم من ١٨،
  التاريخ، ورمزًا فريدًا بصيغة `MV-1234`.

```
├── index.html                 # كل شاشات اللعبة (عنوان، مقدمة، غوص، خريطة، مهمة، نصر، شهادة)

│   ├── fonts/                 # Cairo + Baloo Arabic (woff2 محلية)

│   ├── base.css               # الهوية البصرية والأساسيات
│   ├── microverse.css         # العالم المجهري، بوابة الهروب، الشخصيات، المفاتيح
│   ├── game.css               # الخريطة، واجهة المهمة، النصر
│   └── stage.css              # طبقة المهمات ثلاثية الأبعاد والطباعة
├── js/
│   ├── vendor/three.min.js    # Three.js r147 محلي
│   ├── core/                  # الصوت، الموسيقى، المؤثرات، الشخصيات، الواجهة، المشهد، التقدّم
│   ├── data/content.js        # المحتوى العلمي وكل الحوارات
│   └── missions/m1..m6.js     # المهمات الست
└── tools/                     # بناء الأصوات والصور + اختبارات المتصفح
```

### إعادة توليد الأصوات (اختياري)

الأصوات مضمّنة بالفعل. لإعادة توليدها بعد تعديل نصّ في `js/data/content.js`:

```bash
pip install edge-tts mutagen
python tools/build_voice.py
node tools/voice_coverage.js      # يتأكد أن كل سطر له مقطع يعمل فعلًا
```

الأسطر التي تُنطق من داخل سكربتات المهمات (ردود الفعل على الأخطاء) تُقرأ
تلقائيًا من `js/missions/m6-final.js`، فلا تحتاج تعديلًا يدويًا في `build_voice.py`.

### إعادة توليد صور الشخصيات (اختياري)

المصدر متجهي في `assets/characters/*.svg`. لإعادة إنتاج WebP بعد تغيير الرسم:

```bash
python -m http.server 4180 --bind 127.0.0.1     # في نافذة منفصلة
node tools/render_characters.js                  # يولّد الإطارات في tools/.frames
python tools/build_character_webp.py             # يجمعها في WebP متحرك
```

## 7. الاختبارات

كلها تعمل محليًا وتحتاج Microsoft Edge و`puppeteer-core`:

```bash
node tools/smoke_test.js        # إقلاع سريع: عناصر DOM، الخطوط، الصور، التدفق
node tools/acceptance_test.js   # الشاشات + المهمات الست + الشهادة على ثلاث دقات
node tools/m6_test.js           # المهمة السادسة كاملة حتى الهروب
node tools/voice_coverage.js    # تغطية الأصوات + تشغيل مقطع حقيقي لكل شخصية
node tools/offline_test.js      # التشغيل من file:// بلا خادم
node tools/dialogue_test.js     # زرّة تخطّي الحوار تقطع الصوت فعلًا على ثلاث دقات
```

`acceptance_test.js` يفحص كل زر ظاهر ويتحقق أنه قابل للنقر فعلًا (لا شيء محجوب
بطبقة علوية)، وأن لا عنصرًا أساسيًا خارج حدود الشاشة.

## 8. ملاحظات تقنية

- Three.js r147 (UMD) مضمّن محليًا؛ لا تُحمّل أي مكتبة من CDN.
- الرسوميات إجرائية — لا صور خارجية ولا ملفات نموذج ثلاثي الأبعاد.
- الموسيقى والمؤثرات تُولّد عبر Web Audio API داخل المتصفح، مع موسيقى مستقلة
  لكل سياق: القصة، القائمة، المهمة، التجربة، النهاية، النصر.
- أصوات الشخصيات: مقاطع MP3 عربية جاهزة، مع بديل صوت النظام ثم أصوات كرتونية
  إذا تعذّر تحميل المقاطع — فلا تصمت اللعبة أبدًا.
- الصوت يبدأ بعد أول تفاعل من المستخدم (سياسة المتصفحات)، ويمكن اللعب مكتومًا.
- كل الأصول محلية، ولا توجد أزرار بلا وظيفة.
